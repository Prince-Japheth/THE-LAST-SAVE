MIRA / THE LAST SAVE
A fictional disk from a shuttered night station.

Start with LETTER.RTF. Compare SIGNAL.PCX with
the final record in STARLOG.DBF, then read NIGHT.ANS.

The camera saw an arc. The relay counted seventeen.
The archivist left the image open.

All people, places, dates, and events in this original
demonstration narrative are invented. These files are
newly authored binary fixtures, not historical evidence.

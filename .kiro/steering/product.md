# THE LAST SAVE
A browser-local, read-only obsolete-file archaeology lab. Read README.md, docs/BUILD.md, docs/FORMAT-NOTES.md. Never invent recovered data. Explicit missing-byte reconstruction requires an earlier parity capsule, sufficient redundancy and a matching final SHA-256; retain the damaged input and label the derived output. Treat all imports as untrusted. Archive extraction and decoding belong in bounded workers. Retain originals byte-for-byte, SHA-256 fingerprints, explicit unsupported variants and conversion warnings. The MIRA story is fictional. Fonts and runtime resources are self-hosted.

Current capabilities include browser-local IndexedDB sessions, sound on by default after interaction, bounded PNG/JPEG previews, prior-parity reconstruction, contiguous image carving, and optional first-64-MiB external-disk access through the paired read-only Mac companion. Optional database-free Vercel VAPID push handles subscription metadata only; files stay local. Recovery requires the open tab. No physical disk recovery or device push delivery has been verified. Read docs/NATIVE-RECOVERY.md, docs/PUSH-SETUP.md and docs/VERIFICATION.md for boundaries.
